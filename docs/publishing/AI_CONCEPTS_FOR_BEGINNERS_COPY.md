## 标准简介

LLM、Prompt、Context、RAG、Function Calling、MCP、Agent、Workflow、
Skill、Subagent、LangChain……这些词经常一起出现，但它们并不是同一层
东西。

这期视频不背字典，也不堆技术名词，而是用“一家 AI 餐厅”把 11 个核心
概念串成一套完整关系：

- LLM 是读过大量资料的大脑
- Prompt 是这一次下的订单
- Context 是模型当前能看到的工作台
- RAG 负责从资料库找回相关内容
- Function Calling 让模型提出结构化工具请求
- MCP 给不同工具提供统一的接入方式
- Agent 负责观察、决策、行动和检查
- Workflow 提供稳定、可重复的执行轨道
- Skill 是按需加载的专业操作手册
- Subagent 是负责边界清楚任务的专业分队
- LangChain 是搭建这些零件的一种开发工具箱

看完之后，你不需要死记 11 条定义。只要判断一个概念属于“大脑、信息、
工具、决策还是组织方式”，大多数 AI 系统就能快速看懂。

适合刚接触大模型、AI Agent、RAG 应用和 MCP 的新手观看。
