# Specs And Implementation Plans

`.agents/skills/ai-video-studio-agent-producer/` is the only supported
video-production entrypoint.

Visual production uses code and existing assets only.

The implementation sequence is defined by
`docs/AGENT_PRODUCER_ONLY_ROADMAP.md`.

Dated files under `specs/` and `plans/` are implementation records. They are
not automatically current authority and may describe repository behavior that
was valid only for their original slice.

Use `docs/ITERATION_STATUS.md` to identify the one current bounded plan. Do not
copy historical Web, F5, provider-selection, image-generation, or planner
instructions into new work.

Superseded Web/Planner records that no longer provide Producer implementation
value live under `docs/archive/web-product/`.
